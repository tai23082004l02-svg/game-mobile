Client ID là mã công khai, được lưu trên trình duyệt này. Chủ website cần tạo trong Google Cloud và đăng ký origin https://tai23082004l02-svg.github.io. Không nhập Client Secret hoặc mật khẩu Google.

Bật YouTube Data API v3 trong Google Cloud rồi nhập API key để tìm kiếm và đọc thống kê công khai.

Key chỉ giữ trong bộ nhớ của tab, mất khi tải lại trang. Key được gửi trực tiếp đến Google qua HTTPS. Chỉ dùng API key dành cho web, giới hạn theo website và YouTube Data API v3. Không nhập OAuth token.
